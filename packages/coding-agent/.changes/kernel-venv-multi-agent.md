- Changed the managed Python kernel venv location to `~/.prime/agent/kernel-venvs/<schema>-<runtime-hash>/`, one directory per prime-agent runtime identity, so a source checkout and an installed release (or two builds) no longer rebuild one shared venv underneath each other's running kernels; unused sibling venvs and the legacy `~/.prime/agent/kernel-venv` are removed after seven days without use.
- Fixed repeated Python skill re-installs when sessions with different Python skill sets share a kernel venv: the venv manifest now records the union of installed skills and a session only checks for its own.
- Fixed the kernel bootstrap lock to detect a reused owner pid, report progress while waiting for another prime-agent's kernel setup, stop waiting when the kernel start is aborted, and fail with a clear error naming the lock directory after 15 minutes.
